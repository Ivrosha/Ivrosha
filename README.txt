IVROSHA WEBSITE — FIRST VERSION

Files:
- index.html: home page and journal archive
- posts/: one page per published entry
- styles.css: design and responsive layout

Preview:
Open index.html in a browser.

Publish:
1. Create a GitHub account if you do not already have one.
2. Create a new public repository, for example: ivrosha-website
3. Upload the contents of this folder (not the folder itself) to the repository.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and /(root), then Save.
7. GitHub will provide the public website address after deployment.

To add a new post:
1. Duplicate one of the HTML files inside posts/.
2. Change the title, date, category, and paragraphs.
3. Add a matching article entry to the post-list section in index.html.
4. Upload the updated files to GitHub.

Notes:
- This is a static public website. Anyone with the link can read it.
- There is no login, comments, or private drafts area.
- The site uses Google Fonts; if unavailable, it falls back to system serif/sans-serif fonts.
- The wording of the three entries is preserved from the text supplied in the conversation.
